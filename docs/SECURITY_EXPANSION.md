# Security expansion
Reutiliza verificación manual, permisos internos y locks existentes. El desafío aritmético es una fricción básica, no una prueba fuerte de humanidad. No entrega roles sin revisión. Casos conserva hasta 200 nuevas acciones de comandos warn, timeout, kick y ban y alertas; no importa antiguos ni garantiza registrar acciones nativas o IA. Apelaciones desde el servidor (miembros baneados deben usar soporte externo), revisión administrativa sin reversión automática. Evidencia solo enlaces de mensajes del mismo servidor, no copia contenido. Anti-Nuke opt-in alerta por actor, excluye dueño, bot y whitelist, no bloquea ni sanciona; requiere auditoría y logs. Lockdownall solo dueño y hasta 30 canales de texto; cambia SendMessages de @everyone, otros permisos prevalecen, resultado parcial posible. Datos por Store existente; no modifica Supabase. Pruebas y revisión real pendientes.
