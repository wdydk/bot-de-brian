# Roblox, Translation & Support
Roblox profile lookup uses documented public users and friends count endpoints; no gameplay/TSB statistics unless officially exposed. OAuth authorization code with PKCE and userinfo: configure ROBLOX_CLIENT_ID and ROBLOX_CLIENT_SECRET on Railway, register HTTPS WEB_BASE_URL/roblox/callback and scopes openid profile in Creator Dashboard. Roblox may require application review. Tokens are used transiently and revoked best-effort; only Discord ID, Roblox ID and link timestamp stored in roblox-links.sqlite on volume. Unique account binding, unlink by signed-in user, no role grants. Official docs: https://create.roblox.com/docs/cloud/auth/oauth2-reference and https://create.roblox.com/docs/cloud/auth/oauth2-develop. Translation and support use configured Gemini, explicit input only, private replies, no moderation action, no background reading. Support sends public command catalogue and directs to official support; it does not create tickets automatically. No Supabase adapter changes. CI and actual OAuth/Discord flow still require validation.
