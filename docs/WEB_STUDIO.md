# Web Studio
Refinamiento visual sobre Aurora: módulos públicos agrupados por función con SVG locales, guía de primeros pasos, navegación activa, pie de página, buscador del menú de configuración y diseño móvil. No modifica autorización, comandos, credenciales, persistencia ni acciones de Discord. Las cifras son las mismas estadísticas reales existentes. El menú conserva los módulos no clasificados en Otros módulos y el contenido permanece disponible si falla JavaScript. Se mantienen temas, acentos y movimiento reducido. Pruebas de agrupación, render y HTTP; revisar visualmente en escritorio y móvil antes de desplegar.
